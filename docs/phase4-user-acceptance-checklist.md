# Phase 4 — User acceptance checklist

Use the development app only. Do not reset/clear IndexedDB or edit `BASE_DATA` or the validation workbook. For status/deadline scenarios, use a controlled test record and restore TNP-controlled values by re-importing the same workbook.

1. **Home and navigation:** verify Active, Overdue, Rejected and Completed counts; open each KPI/module link and confirm the resulting view. Home should remain a quick overview, not a second Analysis page.
2. **Records and filters:** check Active / All / Completed, search, Plant + Month, Plant + Status, Project + Model, Status + TAT, and Search + Plant + Status. Open More Filters, confirm unrelated filters remain set, clear filters, manually sort a column, then return to Priority. Resize to a smaller desktop window and check table scrolling and long-text truncation.
3. **Detail and editing:** open a record, review the grouped controls and collapsed source fields, edit PIC, Remark/Notes and CA File Link, save, reload, and verify persistence. Confirm source-only fields remain read-only. Check close button, backdrop and Escape behavior, with visible keyboard focus.
4. **First workbook import:** select `EXCEL_EXPORT_FILE_20261002181424.xlsx` without modifying it. Verify one worksheet, 110 scanned rows, 50 mapped headers, zero invalid rows, blank statuses or final deadlines; import and verify the Records list and import history refresh. In a fresh seeded development database the automated check classified all 110 as New; existing database state may change the first-run counts.
5. **Repeat import and preservation:** import the same workbook again. Expect no duplicates; with no intervening TNP-field changes, expect 0 New, 0 Updated and 110 Unchanged. Confirm local PIC, notes and CA File Link remain unchanged.
6. **Status and deadline behavior:** on controlled development data, change Open → Completed → `Rejected (xét)` and check Active, Completed, Rejected and TAT views/order after each save. Change `dueDate` and confirm the displayed deadline, remaining days, Records priority and TAT bucket update. Re-import the workbook to restore its TNP-controlled status/deadline values.
7. **Drill-down and language:** open representative Analysis category/month/status and TAT bucket/Plant links, refresh the Records URL, and confirm the same subset remains. Review visible labels in English, Vietnamese and Korean.
8. **Errors and empty states:** try an unsupported extension, malformed/empty workbook, missing required headers and an invalid date; confirm import never reports success. Check no-results, no-overdue, no-Rejected, no-Corrective and no-chart-data states; details should remain readable without raw stack traces.
